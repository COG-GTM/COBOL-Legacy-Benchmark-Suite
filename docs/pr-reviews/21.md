## Concerns

The following issues were identified during review (see inline comments on PR for details):

### Blockers

1. **Gain/loss calculation in `_write_history` is incorrect** - The method queries the position after it was updated by `_process_sell`, but then tries to reconstruct the "old quantity" by adding back the sold quantity. However, `cost_basis` has already been reduced, so the calculation uses the reduced cost basis with the original quantity, underestimating cost_per_unit and overstating gain/loss.

2. **Hardcoded placeholder secret key in config.py** - The default value `"your-secret-key-change-in-production"` is a critical security vulnerability if accidentally used in production.

### Major Issues

3. **CORS wildcard with credentials enabled** - `cors_origins = ["*"]` combined with `allow_credentials=True` allows credentialed cross-origin requests from any domain.

4. **Transaction ID generation race condition** - Using `count()` query to determine sequence number means concurrent requests in the same second can generate duplicate IDs.

5. **Batch processing lacks per-transaction atomicity** - No savepoints are used, so partial DB writes from failed transactions are not rolled back.

### Minor Issues

6. **Transfer transaction silently behaves as sell** - Should raise NotImplementedError to match original COBOL behavior (PORTTRAN.cbl explicitly states "Transfer processing not implemented").

7. **Misleading docstrings about cost basis calculation** - Docstring says "weighted average" but implementation stores total cost basis (which matches original COBOL POSREC.cpy).

8. **Broad exception handling leaks internal errors** - Multiple endpoints return `str(e)` for broad exceptions, potentially exposing database constraint messages.

9. **Minimal test coverage** - Only 6 test functions for ~5000 lines of critical financial code.

### Nits

10. **`datetime.utcnow()` deprecated in Python 3.12+** - Should use `datetime.now(timezone.utc)` for future compatibility.

11. **`TimeoutError` shadows Python builtin** - Should be renamed to `PortfolioTimeoutError`.
