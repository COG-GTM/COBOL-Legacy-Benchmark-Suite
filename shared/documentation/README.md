# Shared Documentation

This directory contains cross-platform architecture documentation that applies to both the COBOL and Java implementations of the Portfolio Management System.

## Purpose

- Architecture decisions that affect both platforms
- Migration strategy documentation
- Common business logic specifications
- Shared data model definitions

## Contents

This directory will be populated with documentation as the Java migration progresses, including:

- Architecture Decision Records (ADRs)
- Data mapping specifications
- API contracts and interfaces
- Performance benchmarking results
- Migration guides and best practices
