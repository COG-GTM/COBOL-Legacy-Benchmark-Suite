# Shared Test Data

This directory contains test datasets that can be used by both COBOL and Java implementations to ensure consistency in testing and validation.

## Purpose

- Provide consistent test data across both platforms
- Enable parallel testing during migration
- Support integration testing between COBOL and Java components
- Facilitate benchmarking and comparison

## Contents

Test data will be organized by:

- Transaction test files
- Portfolio position test data
- Historical data samples
- Edge case test scenarios
- Performance test datasets

## Usage

Test data in this directory should be:
- Platform-agnostic (can be consumed by both COBOL and Java)
- Well-documented with expected outcomes
- Version-controlled for reproducibility
- Representative of production data patterns
